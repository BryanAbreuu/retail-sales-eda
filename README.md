# Retail Sales Exploratory Data Analysis

## Overview

This project presents a complete Exploratory Data Analysis (EDA) of a retail sales dataset. The objective was to identify sales patterns, profitability drivers, and business insights that can support future demand forecasting and decision-making processes.

## Business Objectives

- Evaluate data quality and consistency
- Identify missing values and outliers
- Analyze sales and profit distributions
- Explore relationships between key business variables
- Generate actionable insights for business improvement
- Prepare the dataset for predictive analytics

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Deliverables

- Exploratory Data Analysis Report
- Statistical Summary
- Data Quality Assessment
- Data Visualizations
- Business Insights & Recommendations

- Exploratory Data Analysis Notebook (.ipynb)
- Portfolio Report (.pdf)
